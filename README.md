## 先搞清楚：虚拟主机和云服务器到底差在哪

很多人在选购前会卡在这一步。简单说，虚拟主机是"拎包入住"——服务商已经把 Linux + Apache + MySQL + PHP 环境配好，你只需要通过控制面板绑定域名、上传网站程序、点几下就能上线。你不需要 root 权限，也不需要自己装软件。

云服务器则是一台空机器，给你 root 权限，环境自己装，防火墙自己配，安全自己管。灵活度更高，但门槛也更高。

所以判断逻辑很直接：

- 如果你只是想搭一个 WordPress 博客、企业官网、小型论坛，不想碰命令行，虚拟主机够用，而且便宜
- 如果你要跑非 PHP 程序、需要自定义运行环境、要做开发测试、或者对资源隔离有硬性要求，那应该看云服务器

## 常见问题

**虚拟主机能跑 WordPress 吗？**
能。恒创所有虚拟主机全面支持 PHP 5.3 到 8.2，完美兼容 WordPress、ThinkPHP 等 99% 主流 PHP 建站程序，并提供 WordPress 伪静态设置图文教程。下单后还可以联系客服免费安装主流建站程序。

**PHP 版本怎么切换？**
默认安装的是 PHP 5.3。登录控制台后使用"一键切换 PHP 版本"功能，可以自助更换到其他版本。如果遇到问题，可以提交工单联系售后团队协助切换。

**机房不满意能换吗？**
能。在会员中心可以一键切换数据中心，香港多机房之间支持免费切换。对线路或网络不满意，10 秒提交申请，30 分钟内快速切换。

**能建几个站？**
看套餐。基础型号（如 PHP 云主机 Ⅰ型、新云主机 H1、独享版 D1、企业 1G）只能建 1 个站；中档型号有 2 到 5 个站点限制；高档型号（如 PHP 云主机 Ⅲ型及以上、新云主机 H3 及以上、独享版 D3 及以上）不限建站数量。如果站点太多导致资源不足，可以一键升级到更高型号。
